# 吃药提醒（MedReminder）v5.7

一个纯本地运行的安卓吃药提醒小应用，不联网、不要账号、数据只存在手机本地。

## v5.7 当天时间不再跳明天 + 提醒诊断
- 修：之前排定时间会多加 3 秒缓冲，导致「刚好这几秒」的时间被当成已过而推到明天。现在按规则严格判断：晚于当前时刻 → 今天；早于/等于 → 明天。
- 新增 USE_EXACT_ALARM 权限，装完即可用精确闹钟，不需要用户再去允许「准时提醒」。
- 首页每次启动自动重排全部提醒，防止闹钟被系统/清理软件清掉。
- 新增「设置 → 提醒诊断」：逐项列出通知权限、通知类别重要级/铃声/震动、精确闹钟、全屏通知、电池白名单、每个计划的时间与方式、下一次提醒时间；可一键重排、10 秒后测试、清空记录。
- 新增事件记录：排定/触发/发通知/异常都记时间戳，方便定位“不提醒”。

## v5.5 合并时跳过重复计划
- 合并新增时按「药名 + 用量 + 每次时间」判断重复，已存在的直接跳过，只加不一样的。
- 提示里会写「跳过重复 n 个」。

## v5.4 修复勾选框不显示

- 改为自定义视图（说明文字 + 真正的 CheckBox），勾选状态直接读取。

## v5.3 清除时可选择是否删备份
- 清除确认框加一个勾选项「同时删掉备份文件夹里的备份文件」，默认不勾。
- 不勾：备份保留；勾了：二次确认里明确提示备份会一起删掉。

## v5.2 恢复时可选覆盖或合并
- 已有计划 + 备份里也有计划时，恢复前弹三选：取消 / 合并新增 / 覆盖现有。
- 合并模式：现有计划保留，备份计划追加（id 冲突自动换新 id），服药记录按去重后追加。
- 没有计划冲突时仍是一键恢复。

## v5.1 分区备份 + 清除只留备份文件

- 恢复备份只覆盖文件里存在的分区，没选的项目不动；弹窗提示具体恢复了什么。
- 清除所有数据改为「只保留备份文件夹」：计划、服药记录清空，勿扰、提醒方式、主题颜色、识别 Key 全部回默认（通知渠道 ID 保留，避免渠道丢失）。

## v2.8 吃满不响 + 数据备份
- 当天已经吃满计划次数（不管是点通知、还是用「吃过药了」补记的），到点就**不再提醒**，只把明天的闹钟排好，不会白响一次。
- 设置里新增「数据备份」：可以导出药品计划 + 服药记录到一个 json 文件，卸载重装后再「从备份文件恢复」。
- 覆盖安装新版本时数据本来就保留（同一个包名、同一个签名，安卓不会清数据）；只有卸载重装才会清空，所以卸载前先导出。
- 启动时会自动检查老版本可能用过的数据键名，发现就搬过来，避免升级后列表空掉。

## v2.7 手动“吃过药了”
- 首页每个药品右边多了一个「吃过药了」按钮：不在提醒时间去吃的、提前吃的、忘记点通知的，都可以进应用自己补记一次。
- 点一下会先弹窗确认（显示这个药每次多少、今天计划几次、已经记了几次），确认后当天已服次数 +1，首页统计和记录列表立刻更新。
- 只记账，不会自动取消今天剩下的提醒；如果这次是提前吃的，原来那次提醒还会照常响。

## v2.6 识别换成在线 OCR
- 原来的离线识别在这台手机上认不出来，整块换掉：改成拍照/选图后上传到在线文字识别（百度 OCR 优先，没填百度就用 OCR.space 免费 Key），拿回文字再自动解析填表。
- 安装包从 11MB 缩回约 115KB，因为不再打包识别模型和原生库。
- 识别需要联网（新加了联网权限），照片只在识别时上传，不保存、不建账号。
- 「添加计划」页多了一行「识别设置（在线识别 Key）」：填百度 API Key + Secret Key 就用百度高精度识别；不填就默认走 OCR.space 的公共测试 Key（有频率限制，够试）。
- 解析逻辑不变：药名、用量、每天几次、时间、饭前饭后、用处，识别完弹窗核对，可以改。
- 识别服务报错会直接显示原因（没网、Key 错、额度用完、图片没文字），不会再“点了没反应”。

## v2.5 通知类别自动重建（不会再“干没了”）
- 以前手动在系统设置里删掉「吃药提醒」类别后，安卓不允许应用用同一个 ID 再建回来，所以类别会一直不出现。
- 现在打开应用会自动检查：类别不在、或者被关成“无”，就换一个没用过的新 ID 重建，仍然是**默认全开**：重要级（悬浮/横幅）、闹钟铃声、震动、锁屏显示全部内容、角标、呼吸灯。
- 旧被关掉的那个类别会改名成「吃药提醒（已关闭，可删除）」，你自己在系统设置里删掉它就行，不影响新的。
- 应用不再主动删除任何类别，避免再把正在用的类别删没。

## v2.4 拍照自动填表（离线 OCR）
- 添加计划页面最上方新增「拍说明书 / 处方，自动填表」：可以直接拍照，也可以从相册选一张说明书、处方单或手写医嘱照片。
- 应用用内置的离线中文识别引擎（ML Kit 中文文字识别，模型已打包进 APK，**不联网、不上传照片**），自动识别并填好：药品名称、每次用量、每天几次、提醒时间、饭前/饭后、主要管什么（用处）。
- 识别完会弹「识别结果」窗口，把识别到的每一项和原文前几行一起显示出来，确认后直接写入表单；识别不准可以点「重新识别」换一张，也能手动改任何一项。
- 因为带了识别模型和原生库，APK 从约 1MB 变成约 11MB；只支持 64 位和 32 位 ARM 手机（真机手机都是），x86 模拟器上识别不可用。
- 识别是机器读图，手写字迹潦草、照片糊、说明书排版怪异时会漏或错，**保存前请核对一遍**。

- 首页新增「通知类别设置（悬浮通知 / 震动）」按钮；点击后先弹出提示，明确列出要打开的悬浮通知、震动、锁屏显示全部内容，再跳到该类别页面。
- 首页权限提示条里的“打开通知类别”也走同一个提示。

## v1.6 升级迁移通知类别
- 升级安装时不再新建类别，而是沿用已有的“吃药提醒”类别，之前调好的悬浮/震动/锁屏设置会保留；新建出来的多余类别会被自动删除。
- 只有全新安装才会新建默认全开的类别。

## v1.5 通知类别默认值
- 新建干净的通知类别（v3），默认就是：重要级（可悬浮/横幅）、闹钟铃声、震动、锁屏显示全部内容。
- 首页会检测这四项，任何一项被系统或用户关掉都会提示，并可一键跳到该类别设置页。

## v1.4 新增
- 首页新增「打开应用详情」按钮，一点直接跳到系统的本应用信息页（权限、通知、电池、自启动都在这里）。

## v1.3 调整
- 去掉了“显示在其他应用上层”权限和对应提示项，不再请求悬浮窗。

## v1.2 补充修复
- 打开应用时会自动删掉历史遗留的重复通知类别（旧版 `med_remind`），系统设置里只保留一个“吃药提醒”。装好新版后请先打开一次应用再去看通知设置。

## v1.1 修了什么
- 新增「强提醒」：提醒到点用系统闹钟通道（setAlarmClock）唤醒，弹出全屏提醒页 + 循环响铃 + 震动，锁屏也能亮屏显示。
- 通知类别换成新的 `吃药提醒` 通道，解决旧通道被系统调成静音后一直不响的问题。
- 首页新增两个**必开**检查项：
  1. 通知类别「吃药提醒」必须设成“重要”，并允许悬浮通知 / 横幅
  2. 允许“显示在其他应用上层 / 后台弹出界面”（安卓 14 还要求“全屏通知”）
- 测试提醒改成**虚拟药品「测试提醒」**：点“已服用”不会写入任何服药记录，不会给已添加的计划加次数。

## 安装
1. 把 `吃药提醒-v4.3.apk` 传到手机（微信/QQ/数据线均可）。
2. 点击安装，若提示“未知来源”，在弹窗里允许本次安装即可。
3. 打开应用，按首页提示逐个点“去开启”，把下面几项开全：
   - 通知权限（必须）
   - 通知类别 → 打开声音、震动、悬浮通知 / 横幅、锁屏显示全部内容（必须）
   - 全屏通知（安卓 14 及以上的必开项）
   - 准时提醒 / 闹钟权限（安卓 12 及以上）
   - 电池优化白名单（建议；国产系统还要在“自启动 / 后台运行”里放行）

## 使用
1. 点「＋ 添加吃药提醒」。
2. 填写药品名称、每次用量（如 `1片`、`半片`、`10ml`）。
3. 选择饭前 / 饭后 / 随餐 / 不限。
4. 用＋－设置每天分几次吃，每次单独选时间（默认已给常见时间，可改）。
5. 保存后立即生效，到点会全屏弹出提醒并响铃、震动。

提醒页上有三个操作：
- 「已服用」：记录到今日用药记录（测试提醒不会记录）
- 「10 分钟后再提醒」：推迟 10 分钟
- 「先关掉」：只关弹窗，通知仍留在通知栏

首页可以随时开关某个药的提醒、点药品进入编辑、右侧「删除」移除。

## 自测方法
首页点「测试一下提醒（5 秒后）」，会弹出一条「测试提醒」：
- 先停留在应用里测一次，确认有铃声和全屏页；
- 再回桌面、锁屏各测一次，确认后台和锁屏都能弹出来。
测试提醒不记账，可以放心多次点。

## 说明
- 提醒是每天循环的闹钟，重启手机后自动恢复（需要自启动权限）。
- 如果手动在系统里“强行停止”应用，闹钟会被清除，重新打开应用即可恢复。
- 应用为自签名版本；v1.1 与 v1.0 使用同一签名，可以直接覆盖安装、保留原来的药品和记录。若系统提示签名冲突，再卸载重装。
